## Diferença para os cortes
| | Corte | YouTube longo |
|---|---|---|
| Objetivo | parar o dedo, alcance | reter, aprofundar, gerar confiança |
| Ritmo | troca a cada 1,5–3 s | troca a cada 4–8 s, respiros permitidos |
| Texto na tela | grande, o tempo todo | pontual: títulos de capítulo, números, termos |
| Legenda | animada palavra a palavra | opcional / legenda do YouTube |
| Estrutura | gancho → 3 pontos → CTA | gancho → promessa → capítulos → recap → CTA |
